# 🚀 Digital Tools Buying Website

## Description
A web app to explore and buy digital tools like resume builders, portfolio creators, and more. Clean UI with interactive cart system.

## Technologies
- React.js  
- Tailwind CSS  
- JavaScript  
- React Toastify  

## Features
1. Add to Cart with duplicate prevention  
2. Dynamic product rendering from JSON  
3. Responsive and modern UI
